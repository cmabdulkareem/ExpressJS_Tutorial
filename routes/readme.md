## 📁 `routes` Folder

The `routes` folder is created in the root directory to organize and manage all the application's route handlers in a modular way.

### Why Not Define Routes in `index.js`?
- The code becomes cluttered and harder to read.
- It makes the application less maintainable as it grows.
- Adding new routes or modifying existing ones becomes more error-prone.

### Benefits of Using the `routes` Folder
- Keeps the codebase **organized** and **modular**.
- Improves **readability** and overall project **structure**.
- Promotes **reusability** and easier **unit testing**.
- Follows best practices for **scalable application design**.
